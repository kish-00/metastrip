How it works: MetaStrip inspects file containers locally and removes metadata while preserving readable media content whenever a safe method is available. Images and audio often keep structural data and color/orientation information so the file still works. Unsupported, encrypted, or signed formats are reported instead of silently producing a broken copy. Library code is fetched from pinned CDN versions, but your file bytes never leave this browser tab.
